Cyclistic Bike-Share Analysis

📊 Data Analytics | Excel, Power Query

Overview

Analyzed 258,678 bike trips to identify behavioral differences between casual and member riders, providing data-driven recommendations to improve member conversion.

Key Finding: Casual riders spend 30% more time per trip but take fewer rides. Members use bikes for commuting (short, frequent). This insight drove targeted marketing strategies.

Key Findings

  • 76% member rides vs. 24% casual
  • Casual: 30+ min avg | Members: 15-20 min avg
  • Peak hour: 5 PM (8.46% of daily rides)
  • 78% of sub-10-min rides are members
  • Thursday: Highest usage day (13.1% of weekly rides)

Recommendations

  • Create 30-min pass (10 passes/week) for casual riders
  • Peak-hour promotions (3-6 PM)
  • Member referral program with rewards
  • Expand facilities at high-traffic stations
  • Special pricing for low-usage days

Asian Option Pricing with ANN

🤖 Machine Learning | Python, TensorFlow

Overview

Built neural network models for Asian option pricing, achieving 10-100x speedup over Monte Carlo methods while maintaining 90%+ accuracy.

Impact: Enables real-time pricing for derivatives trading, reducing computation from seconds to milliseconds.

Optimal Configuration

  • 2 hidden layers, 50 neurons each
  • ReLU activation, ADAM optimizer
  • Binary Crossentropy loss
  • Early stopping to prevent overfitting

Performance Results

  • 90%+ prediction accuracy
  • ANN: 12ms for 1K prices vs. Monte Carlo: 2.8s
  • 100x speedup at 10K price points
  • R² score close to 1.0

Recommendations

  • Production deployment with TensorFlow/ONNX
  • Quarterly retraining with market data
  • Extend to other option types
  • SHAP explainability for compliance

Fingerprint Recognition Door Lock

🔐 Deep Learning / IoT | Python, CNN, TensorFlow

Overview

Developed CNN-based biometric authentication system achieving 96.72% accuracy on 6,000 fingerprint images for secure IoT door lock applications.

Impact: Provides secure, contactless biometric access control superior to passwords and more convenient than physical keys.

Dataset & Preprocessing

  • Sokoto Coventry Fingerprint Dataset: 6,000 images from 600 individuals
  • Grayscale conversion for efficiency
  • Data augmentation: blur, rotation (±30°), scaling

Model Architecture

  • Feature extraction: Convolutional + Pooling layers
  • Classification: Fully connected layers
  • Best optimizer: ADAM + Binary Crossentropy
  • 20 epochs with early stopping

Results

  • 96.72% classification accuracy
  • Training time: 6 min 29 sec
  • Inference: <100ms (real-time capable)
  • Robust to variations and augmentations

Recommendations

  • Deploy on Raspberry Pi / ARM edge devices
  • Add liveness detection vs. spoofing
  • Multi-modal security (fingerprint + facial)
  • Encrypted template storage
  • Audit logging for all access
