Overview

This project develops a CNN-based biometric authentication system for smart door locks using fingerprint recognition. The system classifies fingerprints with 96.72% accuracy and enables real-time authentication for IoT access control applications.

Impact: Provides a secure, contactless biometric solution for access control that's more reliable than passwords or PIN codes and more convenient than physical keys.

The Challenge

Traditional door locks rely on keys or codes, which are vulnerable to theft, loss, and unauthorized sharing. Biometric systems offer superior security:

  • Fingerprints are unique to each individual
  • Cannot be forged, lost, or stolen (like physical keys)
  • Faster and more convenient than manual key insertion
  • Complete audit trail of access history

The challenge: build a CNN model that can reliably recognize fingerprints with minimal latency for real-time door lock applications.

Technical Approach

Dataset

Trained on the Sokoto Coventry Fingerprint Dataset (SOCOFing):

  • 6,000 fingerprint images from 600 individuals
  • Attributes: gender, hand (left/right), finger (thumb through pinky)
  • Both original and modified versions for robustness
  • Diverse demographic and environmental conditions

Data Preprocessing

Images undergo several processing steps:

  • Grayscale Conversion: RGB 3-channel → single grayscale channel for efficiency
  • Normalization: Pixel values scaled to [0, 1] range
  • Data Augmentation: Introduce variations to improve generalization:
    • Blur (simulates slight out-of-focus captures)
    • Random rotation (±30 degrees, varying finger angles)
    • Scale changes (different finger pressures/distances)

CNN Architecture

The model consists of feature detection and classification layers:

  • Feature Detection:
    • Convolutional layers extract fingerprint patterns (ridges, whorls, loops)
    • Pooling reduces dimensionality while preserving important features
    • ReLU activation introduces non-linearity
  • Classification:
    • Fully connected layers map learned features to class probabilities
    • Binary output: match (1) or no match (0)

Hyperparameter Tuning

Tested multiple configurations to optimize accuracy and latency:

  • Loss Functions: Binary Crossentropy vs. Mean Squared Error
  • Optimizers: ADAM vs. SGD (both at learning rate 0.01)
  • Best Configuration: ADAM + Binary Crossentropy
  • Training: 20 epochs with early stopping to prevent overfitting

Results & Performance

96.72% Classification Accuracy
6:29 Training Time

Model Evaluation

The final model achieves strong performance across metrics:

  • Accuracy: 96.72% on test fingerprints
  • Loss: Minimal (approaching 0)
  • Inference Speed: < 100ms per prediction (suitable for real-time lock operation)
  • Robustness: Handles variations from augmentation (blur, rotation, scale)

Real-time Authentication

System behavior in production:

  • Matched Fingerprint: Output "Success!!" → Door unlocks
  • Non-matching Fingerprint: Output "Fail!!" → Prompt user to retry
  • Multi-attempt Threshold: Lock down after N failed attempts for security

Key Insights

  • Data Quality Matters: Augmentation was critical for handling real-world variations
  • Optimizer Choice: ADAM significantly outperformed SGD for this task
  • Early Stopping: Prevented overfitting and reduced training time by ~30%
  • Latency vs Accuracy: Model is fast enough for real-time use without sacrificing accuracy

Recommendations & Future Enhancements

  • Hardware Integration: Deploy on embedded devices (Raspberry Pi, ARM processors) for true IoT functionality
  • Multi-modal Biometrics: Combine fingerprint with facial recognition or iris scan for enhanced security
  • Liveness Detection: Detect spoofing attacks using fake fingerprints or photos
  • Privacy-Preserving Matching: Store only encrypted fingerprint templates, never raw images
  • Continuous Learning: Retrain model periodically with new fingerprints from authorized users
  • Security Auditing: Log all access attempts with timestamps and confidence scores
