Overview

The Problem with Asian Options

Asian options are financial derivatives whose payoff depends on the average asset price over a set period — not just the final price. This averaging feature makes them complex to price: there's no analytical closed-form solution, so practitioners rely on computationally expensive numerical methods.

This project builds three Artificial Neural Network (ANN) models — each trained on data generated from a different pricing method — to replace those slow numerical computations with near-instant inference.

Core Insight: Once an ANN is trained, it can price thousands of options in milliseconds. The upfront training cost is a one-time expense; the inference speed benefit is permanent.

Background

Asian Options & Pricing Methods

Asian options were first developed by David Spaughton and Mark Standish of Bankers Trust to price oil commodity options in Tokyo. They combine features of Asian and European options — the payoff is based on the average asset price and can only be exercised at maturity.

Three pricing methods were used to generate training data for the ANN:

  • Levy's Approximation: A direct analytical approach that approximates the arithmetic average distribution using lognormal moments. Fast, but limited to short-term options.
  • Monte Carlo with Antithetic Variables: A variance reduction technique using paired random samples. Accurate but requires 10,000+ simulations per price.
  • Quasi-Monte Carlo (Sobol Series): Uses low-discrepancy sequences instead of random numbers for better distribution coverage and faster convergence.

Methodology

Data Generation & Model Architecture

Training data was generated by randomly sampling option parameter combinations and pricing each with all three methods. This produced three separate target datasets — one per ANN model.

End-to-end data processing pipeline for ANN model building

Data Split & Preprocessing

  • 80% training / 20% validation / 10% testing
  • Standardization: all inputs scaled to mean=0, std=1
  • Input features: spot price (S₀), strike price (K), volatility (σ), risk-free rate (r), time-to-maturity (T)

Table 1: Parameter ranges used for synthetic data generation

Optimal Hyperparameter Configuration

  • Hidden Layers: 2 layers, 50 neurons each
  • Activation: ReLU (Rectified Linear Unit)
  • Optimizer: ADAM (Adaptive Moment Estimation)
  • Loss Function: Mean Squared Error (MSE)
  • Early Stopping: Patience = 5 epochs

Conclusions

Key Takeaways & Recommendations

  • Effective Configuration: 2 hidden layers, 50 neurons, ReLU, ADAM, MSE, patience=5 produced the best accuracy/efficiency trade-off
  • Computational Superiority: ANN inference is orders of magnitude faster than all numerical methods at scale
  • QMC Improvement: Use Brownian Bridge Construction (2D Brownian motion) to improve Sobol sequence generation and reduce variance in QMC-trained models
  • Levy Limitation: Levy approximation is limited to short-term options (T parameter assumed equal to T₂). Using real option market prices would improve model calibration
  • Production Path: Deploy with TensorFlow Serving or ONNX Runtime for cross-platform real-time pricing
  • Monitoring: Track prediction drift vs. market prices and retrain quarterly
