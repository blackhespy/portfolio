Case Study

The Challenge

Traditional door locks rely on keys or PIN codes — both vulnerable to theft, loss, and unauthorized duplication. Biometric systems offer a fundamentally more secure solution: authentication tied directly to an individual's physical identity, which cannot be forged or shared.

This project was built by a two-person team with a shared interest in IoT and digitizing physical systems. The goal was to develop a CNN model for fingerprint recognition that could run in real-time on a door lock system with high accuracy and low latency.

Project Goal

Design and train a Convolutional Neural Network that can reliably recognize individual fingerprints from a database of 600 people, with accuracy sufficient for real-world door access control.

Biometric Background

Biometric systems identify or verify individuals based on physiological or behavioral characteristics. Fingerprints have been used for identification since the 1860s — when Sir William James Herschel first applied them to identify criminals and sign contracts.

Key advantages for access control:

  • Uniqueness: No two individuals share the same fingerprint pattern
  • Non-transferable: Cannot be lost, stolen, or shared like a key or password
  • Audit trail: Every access attempt is logged with biometric verification
  • Convenience: No need to carry or remember anything — just your finger

Dataset

Training data sourced from the Sokoto Coventry Fingerprint Dataset (SOCOFing) — a research-grade database designed for academic fingerprint studies.

  • 6,000 fingerprint images from 600 individuals
  • Metadata: gender, hand (left/right), finger position (thumb through pinky)
  • Includes original and pre-modified versions for robustness testing
Sample fingerprint images from the SOCOFing dataset with augmentation examples

Data Preprocessing

Raw fingerprint images required several preprocessing steps before training:

  • Grayscale Conversion: Normalized from 3-channel RGB to single-channel grayscale — reduces dimensionality while preserving all fingerprint structure information
  • Data Augmentation: Applied three transformations to increase diversity and reduce overfitting:
    • Blurring — simulates slightly out-of-focus sensor captures
    • Random Rotation (±30°) — accounts for varying finger placement angles
    • Scaling — simulates different finger pressures and distances from sensor
Data augmentation pipeline — blur, rotation, and scale transforms applied to each image

CNN Architecture

The model is structured in two stages:

  • Feature Detection Layers: Convolutional layers scan the fingerprint image with learned filters to detect ridges, whorls, loops, and bifurcations. Max pooling reduces spatial dimensions while retaining dominant features. ReLU introduces non-linearity between layers.
  • Classification Layer: A fully connected layer maps extracted features to a binary output — match (1) or no match (0).

Prediction Output

In real-time operation, the model processes an incoming fingerprint scan and compares it against the registered database. The output logic:

  • Match (Success): Pattern matches a registered user → displays "Success!!" and unlocks the door
  • No Match (Fail): Pattern doesn't match → displays "Fail!!" and prompts the user to retry

Conclusions & Future Work

  • Proven Performance: CNN achieves 96.72% accuracy on fingerprint pattern recognition with a 6-minute training window
  • Augmentation Impact: Data augmentation was critical — without it, accuracy dropped below 90% due to insufficient sample diversity
  • Hardware Deployment: Next step is deploying the model on Raspberry Pi or Arduino-connected sensor for a fully functional physical door lock
  • Liveness Detection: Add anti-spoofing module to reject fake fingerprints (latex replicas, photographs)
  • Multi-modal Security: Combine with facial recognition for dual-factor biometric authentication
  • Privacy-First Storage: Store only encrypted feature templates, never raw fingerprint images
  • Audit Logging: Log all access attempts with timestamps, confidence scores, and entry/exit records
Key Takeaway

With 6,000 training images and a well-tuned CNN, fingerprint-based authentication is not just academically viable — it's production-ready. The 96.72% accuracy and sub-100ms inference make it directly applicable to real-world IoT access control.
